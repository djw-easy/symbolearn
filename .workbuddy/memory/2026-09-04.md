## 环境踩坑：WorkBuddy 沙箱内 git push 认证
- 现象：用 WorkBuddy 自带 PortableGit 的 `git push` 到达 GitHub 后返回 401，触发交互式 `helper-selector` 凭据选择器并挂起（SIGTERM）。沙箱内网络被限制，ls-remote 等只读操作需在 `dangerouslyDisableSandbox=true` 下才能联网。
- 解决：系统装了 Git for Windows (`D:\Program Files\Git`，自带 `git-credential-wincred.exe`)，可非交互式读取 Windows 凭据库里的 GitHub 凭据。命令：
  `"D:/Program Files/Git/bin/git.exe" -c credential.helper=wincred push origin main`
  （需在 dangerouslyDisableSandbox 下运行；WorkBuddy 自带 PortableGit 无 wincred 二进制，故需直接调用系统 git）。
- 复现提示：ls-remote 不需要认证（公开仓库）可成功，但 push 需要写权限才会暴露凭据问题。
